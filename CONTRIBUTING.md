# Contributing to FileTidy

Contributions improving reliability, accessibility, documentation and tests are welcome.

1. Open an issue describing a reproducible problem or specific improvement.
2. Never include personal data, credentials, secrets, private URLs or unauthorized third-party assets.
3. Run python -m unittest discover -s tests -v before submitting code changes.
4. Keep pull requests narrow, explain testing, and be courteous.
5. Do not manufacture downloads, stars or meaningless contributions.
